# Lisbonne en 72 h avec la Lisboa Card

Itinéraire heure par heure du 24 au 27 novembre 2026, au départ d'Alfama.
Site statique : `index.html` et `style.css`, sans JavaScript ni dépendance à installer.

## Publier sur GitHub Pages

1. Créez un dépôt et envoyez `index.html`, `style.css` et ce fichier à la racine.
2. Dans **Settings → Pages**, choisissez la branche `main` et le dossier `/ (root)`.
3. Le site apparaît à l'adresse `https://<votre-compte>.github.io/<nom-du-depot>/`.

Les polices viennent de Google Fonts. Sans connexion, le site s'affiche avec des polices système.
Horaires et prix à confirmer avant le départ : voir la section Sources du site.
